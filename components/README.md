# Component database

One folder per exact MPN: `components/<category>/<MPN>/`

| File | Content |
|---|---|
| `part.yaml` | structured facts, each with a datasheet `ref` (schema: `_schema/part.schema.json`) |
| `digest.md` | ≤150 lines of notes that do not fit fields |
| `source.yaml` | datasheet URL, revision, SHA-256; CAD sources and licences |
| `symbol/` `footprint/` `3d/` `sim/` | CAD and models (only if licence allows redistribution) |

`index.json` is generated by `comp index`; do not edit it.
Categories in use are whatever folders exist; keep them short and lower-case (`power/buck`, `passive/capacitor`, `mcu/stm32`).
