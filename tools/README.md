# Tools

Deterministic scripts. Every tool prints a short result (`status`, `summary`, `issues`, `artifact`) and writes full logs to a file.

| Folder | Content | Status |
|---|---|---|
| `comp/` | component database CLI | search, get, validate, index, pull, new-project work; ingest, push (M1), cad (M2) planned |
| `calc/` | engineering calculations (buck, LDO, trace width, thermal…) | M4 |
| `altium/` | Altium MCP / DelphiScript wrappers | M3 |
| `reports/` | ERC/DRC/sim log parsers | M3 |
